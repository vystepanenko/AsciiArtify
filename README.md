# AsciiArtify

AsciiArtify is a startup building an ML-powered service that turns images into ASCII art.

This repository holds the infrastructure concept for the Proof of Concept: a hands-on comparison
of local Kubernetes tools (minikube, kind, k3d), the recommendation for the PoC, and a Hello World
demo on the recommended tool.

- [Concept: local Kubernetes for the PoC](doc/Concept.md)
- [Demo manifest](demo/hello-world.yaml)
